# PMSM Field-Oriented Control (FOC) – MATLAB/Simulink

A MATLAB/Simulink implementation of **Field-Oriented Control (FOC)** for Permanent Magnet Synchronous Motors (PMSM).

## Overview

This repository contains a PMSM Field-Oriented Control implementation developed using MATLAB/Simulink. The objective is to provide an accessible engineering reference for students, researchers, and engineers interested in electric motor control and power electronics.

The project aims to demonstrate the fundamental principles of vector control and provide a practical simulation environment for studying PMSM drive systems.

## Objectives

- Demonstrate the operating principles of PMSM Field-Oriented Control.
- Provide practical implementations of coordinate transformations.
- Explore current regulation using PI controllers.
- Understand the interaction between motor dynamics and control algorithms.
- Provide a starting point for further experimentation and development.

## Main Concepts

The implementation covers the fundamental elements of a PMSM FOC system, including:

- Clarke and Park transformations.
- Direct-axis (d-axis) and quadrature-axis (q-axis) current control.
- PI current controllers.
- Inverse Park and Clarke transformations.
- Space Vector Pulse Width Modulation (SVPWM).
- PMSM mathematical modeling and simulation.


## Requirements

- MATLAB (R2021a or higher)
- Simulink
- Simscape Electrical
- Embedded Coder

## Getting Started

1. Clone or download this repository.
2. Open the MATLAB/Simulink project files.
3. Configure the motor parameters and simulation settings if necessary.
4. Run the simulation and explore the control system behavior.

Refer to the individual model files and MATLAB scripts for implementation details.
